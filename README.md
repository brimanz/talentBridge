## 🎯 Descripción del proyecto

**TalentBridge** es una consultora especializada en optimización de perfiles profesionales para profesionales, técnicos y mandos medios latinos. El proyecto digital consiste en una **landing page estática de alta conversión** que presenta:

- Propuesta de valor clara y diferenciada
- Portafolio de servicios (Plan Básico USD $10 / Plan Pro USD $15)
- Tecnología aplicada (IA + metodología ATS)
- Prueba social (testimonios con rating)
- Canales de contacto directos (email, teléfono, WhatsApp)

### Propuesta central
> No vendemos únicamente documentos. Ayudamos a cada candidato a comprender, organizar y comunicar el valor de su experiencia profesional de acuerdo con el mercado y la posición a la que aspira.

## 🛠️ Stack tecnológico

### Frontend
| Tecnología | Uso | Justificación |
|------------|-----|---------------|
| **HTML5 semántico** | Estructura | SEO + accesibilidad |
| **CSS3 Custom Properties** | Estilos | Variables reutilizables, mantenibilidad |
| **JavaScript Vanilla** | Interactividad | Menú móvil, scroll, animaciones |
| **Google Fonts (Inter)** | Tipografía | `font-display: swap` para performance |
| **SVG inline** | Iconografía | 0 requests HTTP, escalable |

### Hosting recomendado
- **Netlify** / **Vercel** / **GitHub Pages** — Deploy estático, CDN global, SSL gratuito.

### Integraciones
- **WhatsApp API** (`wa.me`) — Enlaces directos sin SDK.
- **Schema.org JSON-LD** — Rich snippets en Google.
- **mailto: / tel:** — Protocolos nativos.
